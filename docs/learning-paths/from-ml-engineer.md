# From ML Engineer

> **Level:** INT → ADV · **Time to job-ready:** 10 weeks (10h/week)

## Your unfair advantages

- You already know training, evaluation, serving, monitoring.
- The jump from "deploy a model" to "deploy an agent" is mostly architecture.

## Your gaps

- Prompt sensitivity and context engineering (very different from feature engineering).
- The economics of API vs self-host.
- Tool-use patterns.
