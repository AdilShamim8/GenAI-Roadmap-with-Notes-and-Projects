# From Zero

> **Level:** BEG · **Time to job-ready:** 24 weeks (10h/week)

## Reality check

Going from zero to a job-ready GenAI engineer in 6 months at 10 hours/week is aggressive but possible if you have basic programming fluency (Python, Git, HTTP). If you don't, add 8 weeks for a Python + web fundamentals crash course first.

## Prerequisites

Before starting Rung 0, you should be able to:
- Write a 50-line Python script that calls a REST API and parses JSON.
- Use Git to commit, push, branch, and open a PR.
- Explain HTTP verbs and status codes.
- Read a stack trace and Google the error.

If any of these are shaky, spend 2–4 weeks on [`docs/prereqs.md`](../prereqs.md) first.

## Projects to prioritize

1. **Project 1: Structured-output extractor** — quick win, builds confidence.
2. **Project 2: Hybrid RAG over a Notion workspace** — your portfolio centerpiece.
3. **Project 5: Multi-agent research pipeline** — the project that signals "I can build agents."

## Field guide reading

Read all of `field-guide/` in order. Don't skip the salary bands section — knowing your market matters.

## Anti-pattern

The #1 reason zero-to-job attempts fail: tutorial hell. Every week, you must ship *something* — a script, a notebook, a PR. Reading without doing is decay.
